# Spacecraft-Telemetry-Anomaly-Detection
Spacecraft constantly transmit telemetry data (sensor readings like temperature, battery voltage, and pressure). Build a deep learning model, such as an Autoencoder or LSTM (Long Short-Term Memory) network, to reconstruct this continuous sensor data and flag anomalies that could indicate hardware failure.

## Executive Summary
In orbital operations, reactive maintenance is impossible. When a satellite component fails, you cannot halt the supply chain or dispatch a repair crew; you must detect the degradation mathematically before the hardware physically breaks.
